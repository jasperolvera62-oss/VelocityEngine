What you can do with it

A real engine loop: launch the Hub, create an account, pick a template, open it in the editor and play the demo — all from one build.

⌂

Unity-style Hub

Sign in or create an account, then manage Projects, Templates and Installs from one launcher. Open any project directly in the editor.

▲

2D & 3D templates

Start from Blank 2D, Blank 3D, 2D Platformer, 3D First-Person or the Parkour 3D sample. Each seeds a runnable level with one click.

◎

Jolt physics

Rigid bodies, ray casts, ground probes and a kinematic character capsule. Drop physics balls, tune gravity and watch everything bounce in the editor.

⚡

Parkour movement toolkit

Deterministic 120 Hz movement: sprint curves, variable hold-jump, coyote time, jump buffering, kerb auto-step and ground snap — all data-driven.

⚙

Live tuning editor

Tweak movement and physics sliders while the run plays, then persist your options straight into the project (project.json).

🔒

Local accounts

Create an account in the Hub. Passwords are hashed with PBKDF2-HMAC-SHA256 and projects are owned per user — cloud sync is on the roadmap.

Game templates

Every template ships a working level and its own movement tuning. Create a project from any of them in the Hub with one click.
